# Login Page

Página de login feita com HTML e CSS puros. Tem uma tela de boas-vindas à esquerda e um formulário com efeito de vidro desfocado (blur) à direita, sobre uma imagem de fundo.

> **Aviso importante:** o design, o layout e o posicionamento dos elementos **não são criação minha**. Recriei a página acompanhando uma videoaula do canal **Codehal** no YouTube, como exercício de estudo.

## Status

- ✅ Versão desktop (HTML e CSS)
- ⏳ Versão mobile (ainda não feita)
- ⏳ Versão com JavaScript (ainda não feita)

## Sobre o exercício

O objetivo foi praticar layout, posicionamento e estilização de formulários, reproduzindo uma página de referência e entendendo como cada parte funciona. A página se divide em duas áreas:

- **Boas-vindas:** logo, título, texto de apresentação e ícones de redes sociais com efeito de hover.
- **Formulário de login:** campos de e-mail e senha com ícones, opção "lembrar de mim", link de recuperação de senha, botão de entrada e link para criar conta.

Também tem um menu de navegação (Home, Sobre, Services, Contact) e uma barra de pesquisa no topo.

## Tecnologias

- HTML5
- CSS3

## Conceitos praticados

- Posicionamento com `position: absolute` e `relative`
- Centralização com `transform: translate`
- Flexbox
- Efeito de vidro com `backdrop-filter: blur()`
- Estilização de inputs e labels
- Transições e efeitos de hover
